## GitHub 在线差异升级

- 新增「评论审核 → 在线升级」，按 GitHub Releases 的正式版本号检查更新，支持手动检查和每天两次自动检查，安装需管理员主动执行。
- 只下载和替换新增、变更的文件；未变文件保持原样，旧版已移除的文件按清单删除，额外本地文件保留。
- 文件与数据库使用持久恢复日志、备份和升级锁；失败整体恢复，进程中断后在下次请求加载前恢复。
- 跨版本升级按版本顺序执行独立数据库变更文件，在插件表副本上迁移后切换；MySQL DDL 隐式提交不会破坏原表回滚能力。
- 增加 SHA-256、文件大小、路径和 PHP 语法校验，以及独立请求的新代码加载验收；本地定制冲突会阻止升级。
- 发布工具和 GitHub Actions 生成正式安装包及差异清单，包含真实 MariaDB 的升级与恢复测试。

### 首次启用

1.4.0 没有在线更新客户端，需先手动上传一次下方 `AICommentAudit-1.5.0.zip`。以后在「评论审核 → 在线升级」执行差异升级，无需重复下载整包。

当前支持单站点；需要插件目录可写、可访问 GitHub、数据库迁移权限及可用的本站回环请求。升级时会短暂暂停站点请求，失败时保留恢复记录并回滚。新功能使用说明和发布规范见 [在线升级文档](https://github.com/RainReiki/AICommentAudit/blob/main/docs/online-updates.md)。

此版本基于 GitHub 公开版，不包含主题定制版的改动。

验证：14 组真实 MariaDB 升级、并发与故障恢复场景通过；独立 WordPress 7.1.5 完成真实 HTTP 加载验收、跨版本迁移及验收失败后的文件和数据库回滚。
