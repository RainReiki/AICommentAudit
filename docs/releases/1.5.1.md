## 修复在线升级页面 404

- 修复升级子菜单先于父菜单注册导致的错误侧边链接及页面权限钩子。
- 「评论审核 → 在线升级」现在使用正确的后台页面地址。
- 增加真实登录 WordPress 后台后的 HTTP 回归测试，覆盖菜单、检查更新、升级提交、失败回滚和成功跳转。

### 1.5.0 用户的处理方式

请在 WordPress 后台「插件 → 安装插件 → 上传插件」中上传下方 `AICommentAudit-1.5.1.zip`，选择替换现有版本。因为旧版升级入口本身有问题，需要手动安装一次修复包；已有设置和审核记录保留，之后可正常使用在线差异升级。

本版不修改数据库结构，并保留全部历史迁移文件。
