# AICommentAudit

> WordPress 评论审核插件：本地规则 + AI 审核。  
> 适用环境：WordPress 7.1.5、PHP 8.0+、MySQL / MariaDB

AICommentAudit 把评论审核拆成三层：

```text
本地规则先拦截明显垃圾
→ AI 结合文章、回复上下文、评论者资料和信誉判断
→ 最终给出通过 / 待审 / 拒绝
```

## 功能

- 本地硬规则：违禁词、IP / 邮箱 / 网址黑名单；
- 非中文评论规则：无中文且英文占比达到阈值时，可本地直接拒绝或继续 AI 审核；
- 本地预检：同一 IP 频率、重复评论、链接数量、疑似词；
- AI 审核：DeepSeek 官方或 OpenAI 兼容中转站；
- 支持 `/v1` 自动补全、完整 endpoint、SSE、模型列表、思考模式、最大 token；
- API 令牌额度：按日 / 月 / 累计限制，超限后新评论转待审，不再请求接口；
- 回复评论参考父评论和上级对话；
- 身份检查：AI 0–10 分，高风险直接拒绝，中风险待审；
- 信誉体系：新用户 / 普通用户 / 老访客 / 白名单；
- 审核日志、详情、人工通过 / 待审 / 垃圾；
- 信誉管理、历史扫描和批量处理；
- 原生评论列表审核状态列；
- 测试连接并显示耗时；
- GitHub Releases 在线差异升级、失败回滚与跨版本数据库迁移。

## 安装

1. 下载 Release 中的 [AICommentAudit-1.5.0.zip](https://github.com/RainReiki/AICommentAudit/releases/download/v1.5.0/AICommentAudit-1.5.0.zip)；
2. 后台 → 插件 → 安装插件 → 上传 zip；
3. 启用插件；
4. 打开「评论审核 → 设置」，填写服务地址、API Key 和模型；
5. 保存后点「获取模型列表」选择模型，再点「测试连接」。

从旧版 `CommentAudit 1.0.0` 升级时，插件会自动迁移设置和数据库表。

## 在线升级

先手动安装一次 1.5.0 正式 ZIP，以后打开「评论审核 → 在线升级」检查 GitHub Releases 并执行升级。插件只下载差异文件，未变文件不写入；失败时恢复文件和插件数据库，跨版本依次执行每个版本的数据库变更文件。每天两次自动检查，不自动安装。

数据库迁移先在副本上执行，成功后切换；升级中断由恢复日志在下次请求自动恢复。当前支持单站点，需要目录写权限、数据库迁移权限和可用的本站回环请求。检测到与升级冲突的本地定制时停止升级。

[使用说明、事务边界与发布规范](docs/online-updates.md)。

## 令牌额度怎么填

「设置 → 额度」里的令牌额度是插件本地的熔断线，不是服务商账户余额。填 `0` 表示不限制。

一次审核大约消耗 **3,000–6,000 tokens**（包含文章上下文、提示词和模型输出）。建议：

- 额度 = 每月预计评论数 × 5,000 × 1.2
- 额外留 **20% 缓冲**，因为最后一次调用可能略超剩余额度
- 例：300 条/月 ≈ 1,800,000；1,000 条/月 ≈ 6,000,000
- 测试可先填 `100,000`；小站可用 `1,000,000–5,000,000`

周期可选每日 / 每月 / 累计。测试连接、历史扫描也会计入用量，命中缓存不计；如果中转站不返回 `usage.total_tokens`，额度不会累计。

## 非中文评论规则

打开「评论审核 → 设置 → 本地预检」，开启「非中文评论规则」，设置英文占比阈值（1–100%，默认 80%），再选择「直接拒绝」或「继续 AI 审核」并保存。升级后默认关闭，已有设置保留。

仅检查评论正文。去除 HTML 标签、解码 HTML 实体并排除空白和不可见格式字符后，以英文字母数除以正文总字符数；英文包括 A–Z / a–z 及全角形式，数字、标点、表情计入总数。不含任何汉字且占比大于或等于阈值才触发，例如 `abcd1` 为 80%。有汉字、只有数字或表情、无英文字母的正文不会触发。

直接拒绝不调用 AI，评论以垃圾状态保存，日志记录本地拒绝原因。继续 AI 审核仍执行频率、重复评论等后续检查，再按现有 AI、身份和信誉流程决定；接口异常、缺少密钥或额度用尽仍转待审。黑名单和违禁词保持优先，管理员免审行为沿用现有逻辑。

历史扫描同样遵循此规则；选择「仅本地规则」时，命中且配置为继续 AI 的评论显示待审，需改用「本地 + AI」完成复核。扫描仍只显示结果，不自动更改已有评论。

## 被拒绝的评论

按 WordPress 惯例保存为 **垃圾（spam）**，不会公开显示；待审评论进入 WordPress 待审核队列。

## 隐私

发送给 AI 的内容包括：评论内容、昵称、邮箱前缀与域名、网址域名、文章标题/原文/摘要、回复上下文、评论者信誉统计和身份历史摘要。不会发送完整邮箱、IP、网址路径或参数。
